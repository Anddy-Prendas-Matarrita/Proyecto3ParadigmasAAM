Detailed Description

Validacion semantica del modelo intermedio y generacion del reporte.

Detecta entidades duplicadas, relaciones con entidades no declaradas, reglas fuera del dominio y secciones obligatorias ausentes. Los nombres se comparan por su atomo Prolog, de modo que Sofia y sofia (o con tilde) se consideran el mismo elemento.
